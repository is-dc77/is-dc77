# Sitio web de Jennifer Muñoz

**Área:** desarrollo web · **Proyecto:** sitio de servicios profesionales

[Visitar sitio](https://jenni.cl)

## Objetivo

Presentar los servicios de Jennifer Muñoz y facilitar que las personas conozcan su propuesta y consulten por WhatsApp.

## Trabajo presentado

La página reúne presentación, áreas de acompañamiento, trayectoria, información de sesiones y llamadas a la acción para contactar. El HTML incluye navegación por secciones, acceso a reseñas, selector de idioma y un botón flotante de WhatsApp.

## Evidencia técnica disponible

El archivo HTML revisado contiene estructura semántica, configuración de viewport, descripción para buscadores, textos alternativos en imágenes y atributos de accesibilidad en controles. Referencia una hoja CSS y un archivo JavaScript externos.

La presencia de un control en el HTML no acredita por sí sola su funcionamiento: el selector de idioma, el menú y las reseñas deben verificarse junto con sus archivos correspondientes.

## Alcance de esta ficha

Caso de portafolio basado en el HTML conservado. Esta carpeta todavía no contiene el sitio completo ni permite ejecutarlo localmente. Las fotografías, marca y contenidos de Jennifer pertenecen a sus respectivos titulares.
